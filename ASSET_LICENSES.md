# Asset licenses

California Drive ships **no third-party audio**; every sound is synthesized. The only third-party models are **CC0** vehicles and debris parts from Kenney's Car Kit. Everything else is generated by project code at runtime, including the player cars, buildings, landmarks and props. Third-party files are limited to the open map/elevation data, a small set of **CC0** textures and one **CC0** sky HDRI from Poly Haven, **CC0** Kenney models, input glyphs and reticles, and **SIL OFL** fonts from Google Fonts, all listed below. If any of them fail to load, the game falls back to its procedural textures and system fonts. New assets must go through [docs/05-asset-intake-template.md](docs/05-asset-intake-template.md) before they are committed; `tools/fetch-assets.ts` re-downloads exactly this set.

## Datasets

### OpenStreetMap extracts (roads, buildings, parks, piers, trees, signals)
- Status: approved
- Type: dataset (derived database)
- Source URL: https://www.openstreetmap.org — fetched once per district via the Overpass API (`tools/import-city.ts`), cached locally in `data/raw/` (not committed)
- Creator: OpenStreetMap contributors
- Exact license: Open Database License 1.0 (ODbL-1.0) — https://opendatacommons.org/licenses/odbl/1-0/
- Evidence: https://www.openstreetmap.org/copyright (checked 2026-10-14)
- Attribution required: yes — "© OpenStreetMap contributors" shown on the title screen, loading screen, credits page and in every `district.json` `attribution` field
- Redistribution allowed: yes, under ODbL (share-alike applies to the derived database)
- Modification allowed: yes
- Trademark / brand risk: low — street names only; landmark names in the game are generic descriptions, not trademarks
- Size: 0.5–2.4 MB per district JSON
- Optimization plan: projected to local meters, rounded to 0.1 m, simplified footprints, elevation as base64 Int16
- Local paths: `public/cities/<id>/district.json`
- Modifications: clipped to bbox, split at junctions, densified, heights derived, buildings over road centerlines removed, building outlines replaced by their parts, signals moved to junctions
- Notes: The derived district files are a Derivative Database and are offered under the ODbL. Runtime never contacts OSM servers.

### AWS Open Data "Terrain Tiles" (elevation)
- Status: approved
- Type: dataset (elevation raster, terrarium PNG encoding)
- Source URL: https://registry.opendata.aws/terrain-tiles/ (s3://elevation-tiles-prod)
- Creator: Mapzen / Linux Foundation; source data includes USGS 3DEP / NED (U.S. public domain), SRTM, GMTED and others
- Exact license: Various open licenses per source; U.S. coverage is USGS public domain. Attribution text per https://github.com/tilezen/joerd/blob/master/docs/attribution.md
- Evidence: registry page and joerd attribution doc (checked 2026-10-14)
- Attribution required: yes — "Elevation: AWS Terrain Tiles (USGS 3DEP and other open sources)" on loading screen and credits
- Redistribution allowed: yes (derived grid embedded in district JSON)
- Modification allowed: yes (resampled, 3×3 smoothed)
- Trademark / brand risk: none
- Local paths: elevation grid inside `public/cities/<id>/district.json`

### California relief heightmap (city select)

## Branded vehicle — personal use only
### BMW M3 Competition (G80) approximation
- Status: **approved for personal, non-commercial use only — not for public deployment without a license from BMW AG**
- Type: procedural model + specs (`src/vehicle/m3Model.ts`, `M3_COMP` in `src/physics/vehicle/config.ts`)
- Source: written from scratch in code from public dimensions/specifications; no ripped meshes, no official artwork, no BMW-supplied files
- Trademark / brand risk: **high** — BMW, M3, M, the roundel and the kidney-grille trade dress are BMW AG trademarks; badges are procedurally drawn approximations
- Mitigation: "Manufacturer badges" toggle (Car & Assists) hides all marks; the fictional Vireo S6 remains available; credits page carries a non-affiliation notice
- Release rule: before any public deploy, switch the default vehicle to `vireo` (`src/core/settings.ts`) and/or remove `m3c` from `src/vehicle/vehicles.ts`, or obtain a license
- Added at the owner's explicit request (2026-10-15)

## Rejected / not used
- Branded Porsche models, logos and model names: not used (trademark/trade dress).
- Ripped or downloaded BMW 3D models (game rips, unlicensed Sketchfab/Turbosquid assets): never used.
- Google Maps / Street View geometry or imagery: never used.
- Unreal Engine "City Sample" (Matrix Awakens) and Synty / Unity Asset Store packs: their EULAs only allow use inside those engines, so they cannot ship in a WebGL game. Not used.
- TurboSquid / CGTrader / Free3D / Open3DModel / Sketchfab "free" models: you need an account to download them, and the licenses vary from model to model (often CC-BY with attribution, "editorial" or personal use only). Nothing is taken from them without a per-model intake review (docs/05). The pier Ferris wheel is built in code instead.
- Rive animations: Rive's runtime is MIT, but `.riv` files have to be authored in the Rive editor. The lock-on reticle and HUD boot are coded as a small state machine instead (`src/ui/targetLock.ts`, `src/ui/motion.ts`); a `.riv` could replace them later.
